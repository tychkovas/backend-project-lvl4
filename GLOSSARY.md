# Task Manager

Веб-приложение для постановки и отслеживания задач между участниками команды: автор создаёт задачу, назначает исполнителя, задача проходит через статусы и помечается метками.

## Language

**Задача (Task)**:
Единица работы с названием, описанием, статусом, автором, опциональным исполнителем и набором меток. Название задачи уникально.
_Avoid_: тикет, issue

**Статус (TaskStatus)**:
Элемент справочника состояний, через которые проходит задача. Ровно один статус назначен задаче в каждый момент.
_Avoid_: состояние, stage, прогресс

**Метка (Label)**:
Элемент справочника тегов для группировки задач. Задача и метка связаны «многие ко многим».
_Avoid_: тег, категория

**Пользователь (User)**:
Аккаунт в системе с именем, фамилией и email. Выступает автором или исполнителем задач.
_Avoid_: клиент, участник

**Автор (Creator)**:
Пользователь, создавший задачу. Роль неизменна после создания задачи — редактирование не переводит авторство.
_Avoid_: владелец

**Исполнитель (Executor)**:
Пользователь, назначенный на задачу для её выполнения. Может отсутствовать (задача не назначена).
_Avoid_: assignee как отдельная сущность, владелец
